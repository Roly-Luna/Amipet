# AmiPet TB3

Prototipo web responsive para la adopcion responsable de mascotas.

## Tecnologias
- HTML5 semantico
- CSS3 puro
- Figma para los mockups

## Estructura
- `index.html`: landing page
- `css/styles.css`: hoja de estilos compartida
- `img/`: ilustraciones locales
- `pages/`: pantallas de la aplicacion
- `SPEC.md`: reglas tecnicas

## Ejecucion
Abrir `index.html` con Live Server en Visual Studio Code.

## Alcance
Interfaces estaticas con HTML y CSS. Sin JavaScript, autenticacion real, persistencia, APIs ni IA funcional.
